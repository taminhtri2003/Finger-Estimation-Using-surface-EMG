Mathematical Aspect: The Objective Function

The counterfactual search aims to minimize a total loss function ($\mathcal{L}_{total}$) by adjusting the latent vector $z$. This loss combines the different objectives, weighted by $\lambda$ values (which you can adjust conceptually above):

$$ \min_{z} \mathcal{L}_{total}(z) = \lambda_{model} \mathcal{L}_{model}(G(z)) + \lambda_{prox} \mathcal{L}_{prox}(G(z), x_{orig}) + \lambda_{bio} \mathcal{L}_{bio}(G(z)) + \lambda_{gan} \mathcal{L}_{gan}(G(z)) + \lambda_{latent} \mathcal{L}_{latent}(z, z_{initial}) $$

Where:

  • $z$ is the latent vector being optimized.
  • $G(z)$ is the EMG generated from $z$.
  • $x_{orig}$ is the original EMG signal.
  • $\mathcal{L}_{model}$ measures the difference between the predictor's output for $G(z)$ and the target angles (e.g., Mean Squared Error).
  • $\mathcal{L}_{prox}$ measures the distance between the generated EMG $G(z)$ and the original $x_{orig}$ (e.g., L1 or L2 norm).
  • $\mathcal{L}_{bio}$ is the penalty for biomechanical implausibility (e.g., agonist/antagonist co-contraction).
  • $\mathcal{L}_{gan}$ encourages the GAN Discriminator to classify $G(z)$ as real (e.g., Binary Cross-Entropy vs. target '1').
  • $\mathcal{L}_{latent}$ measures the distance between the current $z$ and the initial $z_{initial}$ (e.g., L2 norm).

Summary

This interactive exploration demonstrates the core principles of predicting hand angles from sEMG and using advanced offline XAI techniques (GANs, Latent Space Counterfactuals) to understand and analyze the system's behavior. While the real-time prediction uses a fast, trained model, the explanations require more complex, computationally intensive offline analysis involving generative models and multi-objective optimization concepts.
